# 2026-09-22

## xcodebuild 构建 / 运行验证

结论：可用 xcodebuild 正常构建并运行。

环境：
- Xcode 27.0 (27A266a)，XcodeGen 2.46.0
- 本机仅安装 iOS 27.0 模拟器运行时（24A434）
- 已启动设备：iPhone 18 Pro

构建命令（derivedData 输出到 `.scratch/DerivedData`，不污染系统）：

```sh
xcodebuild -project ExternalDisplayDemo.xcodeproj \
  -scheme ExternalDisplayDemo -configuration Debug \
  -destination 'platform=iOS Simulator,name=iPhone 18 Pro' \
  -derivedDataPath .scratch/DerivedData build
```

结果：clean build 成功，无编译告警（仅 appintentsmetadataprocessor 的
"Metadata extraction skipped, no AppIntents.framework dependency found" 提示，无害）。

运行命令：

```sh
APP=.scratch/DerivedData/Build/Products/Debug-iphonesimulator/ExternalDisplayDemo.app
xcrun simctl install booted "$APP"
xcrun simctl launch booted com.jove.externaldisplaydemo            # 默认
xcrun simctl launch booted com.jove.externaldisplaydemo -mockExternalDisplay   # 带模拟外接屏
xcrun simctl io booted screenshot .scratch/shots/launch.png
```

验证结果：
- 默认启动 → 显示「未检测到外接屏」，符合模拟器限制，无崩溃。
- `-mockExternalDisplay` → 模拟外接屏窗口正常挂载，图案画布 + 逐帧动画均在渲染。
- 无 crash report 产生。

产物 Info.plist 用 `plutil -p` 确认正确：`UIApplicationSupportsMultipleScenes = true`，
两个 role（`UIWindowSceneSessionRoleApplication` / `...ExternalDisplayNonInteractive`）
的 `UISceneDelegateClassName` 均已正确展开为 `ExternalDisplayDemo.MainSceneDelegate`
与 `ExternalDisplayDemo.ExternalDisplaySceneDelegate`。

注意：本机只有 iOS 27 运行时，因此走的必然是 iOS 27 的
`registerSceneAccessory(_:)` 路径（README 中描述的 iOS 27+ 行为），
iOS 17~26 的「plist 自动连接」路径在当前环境下无法实测。

截图存于 `.scratch/shots/`。

## 补充：全配置构建覆盖（同日续）

| 配置 / 目标 | 命令要点 | 结果 |
| --- | --- | --- |
| Debug / iOS Simulator | `-destination 'platform=iOS Simulator,name=iPhone 18 Pro'` | BUILD SUCCEEDED，无告警 |
| Release / iOS Simulator | 同上，`-configuration Release` | BUILD SUCCEEDED，无告警 |
| Debug / 真机架构 | `-destination 'generic/platform=iOS' CODE_SIGNING_ALLOWED=NO CODE_SIGNING_REQUIRED=NO` | BUILD SUCCEEDED |

三个配置都只产出同一条无害提示（appintentsmetadataprocessor / 无 AppIntents 依赖）。

真机产物校验：`lipo -info` → arm64；`otool -l` 的 `LC_BUILD_VERSION` → `minos 17.0`，与
`IPHONEOS_DEPLOYMENT_TARGET` 一致。

`-mockExternalDisplayAspect` 参数实测有效：
`xcrun simctl launch booted com.jove.externaldisplaydemo -mockExternalDisplay -mockExternalDisplayAspect=4:3`
→ 面板显示 `1086 × 814 px @3.0x`（比值 1.334，即 4:3），确认参数被解析。

真机编译用 `CODE_SIGNING_ALLOWED=NO` 绕开证书即可，无需开发者账号。
各配置分别用独立 derivedData（`.scratch/DerivedData` / `DD-release` / `DD-device`），
可并行执行互不干扰。

截图：`.scratch/shots/launch.png`（16:9 mock）、`launch-default.png`（默认）、`launch-4x3.png`（4:3 mock）。
