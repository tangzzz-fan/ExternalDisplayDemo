## 新建 ExternalDisplayDemo（external display 接入 demo）

- 目的：验证 iOS 17 起接入外部显示器的最小可运行工程，工作区 `/Users/jove/Developments/ExternaldisplayDemo`。
- 技术选型：XcodeGen（project.yml），deployment target **iOS 17.0**，bundle id `com.jove.externaldisplaydemo`，
  scheme 名 `ExternalDisplayDemo`。接入层 UIKit（scene + window），UI 用 SwiftUI。
- 已用 `xcodebuild` 对模拟器（iPhone 18 Pro / iOS 27.0 运行时）与 `generic/platform=iOS` 双目标验证，
  均 BUILD SUCCEEDED 且零 warning。

### 关键 API 结论（从 iOS 27 SDK 头文件核实，非记忆）

- `UIScreen.screens` / `didConnectNotification` / `didDisconnectNotification` 均 `API_DEPRECATED(ios(3.2, 16.0))`；
  `UIScreen.main` `API_DEPRECATED(ios(2.0, 26.0))`。屏幕信息只能从 `windowScene.screen` 取。
- 正确 role：`UISceneSession.Role.windowExternalDisplayNonInteractive`（iOS 16.0+）。
  旧的 `windowExternalDisplay` 已 `API_DEPRECATED_WITH_REPLACEMENT(ios(13.0, 16.0))`。
- **最大坑**：Apple 文档明确 *Beginning in iOS 27, your app receives a scene with the
  windowExternalDisplayNonInteractive role only after it registers a scene accessory.*
  配套 API 全在 iOS 27.0：`UISceneAccessory.externalNonInteractive(sceneConfiguration:)`、
  `UIViewController.registerSceneAccessory(_:)` / `unregisterSceneAccessory(_:)`、`UISceneConnectionOptions.sceneAccessoryUserInfo`。
  → iOS 17~26 靠 Info.plist 声明即可自动连接；iOS 27+ 必须额外注册 accessory。
  失败表现是**静默镜像**（外接屏只把手机竖屏 letterbox 过去，无报错无日志）。
- 外接屏 window 用 `isHidden = false` 而非 `makeKeyAndVisible()`，避免抢走手机屏 key 状态。
- `UIRequiresFullScreen = YES` 会让 iPhone 直接失去外部显示器能力；`UIApplicationSupportsMultipleScenes` 必须为 YES。
- `$(PRODUCT_MODULE_NAME)` 展开需用 `plutil -p` 校验构建产物 Info.plist，写错同样是静默镜像。

### 调试手段

- 模拟器不支持外接显示器，工程内置 `-mockExternalDisplay` 启动参数（已挂 scheme，默认关），
  在手机 scene 上叠 16:9 letterbox 窗口挂同一份 `ExternalDisplayRootView`，
  并登记为 `source == .mock` 的 attachment；手机端有开关可随时收起（PassthroughWindow 的 hitTest 返回 nil，不吞触摸）。
  可选 `-mockExternalDisplayAspect=4:3`。

### 过程中踩到的自身问题（记录以免重犯）

- 最初把手机端 rootViewController 换成「容器 VC + 子 UIHostingController」后整屏空白。
  改为直接 `class PhoneRootViewController: UIHostingController<PhoneRootView>` 后恢复正常。
  → 结论：外部屏接入场景不要引入手工子视图布局，直接继承 hosting controller。
